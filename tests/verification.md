# 初期版の検証記録

2026-09-06、Windows / Microsoft Edge（Playwright経由）で本番ビルドを確認。

- `yarn build`：strict型チェック＋Viteビルド成功。
- `yarn test`：ブラウザ用に適応したWasmで、曲線・多角形・ピクセル・白黒の出力と不正入力を検証。
- ロゴ・イラスト・白黒線画・ピクセルアートの4プリセットを実変換。
- 出力にpathが存在し、ラスター埋め込みのimage要素がないことを確認。
- SVGダウンロードの内容とファイル名、クリップボードへのコードコピー。
- PNG・JPEG・WebPの読み込みと変換。
- 透明PNGの出力をCanvasに描画し、背景のalpha=0と図形のalpha=255を確認。
- 設定変更で出力が無効になること、カスタム表示、リセット。
- キャンセルと再実行、変換中の画像差し替え。
- Wasm取得失敗のエラー表示と、その後の再実行。
- 非対応形式、破損画像、20 MiB超過、2400万画素超過の拒否。
- 全透明画像は入力時に案内して拒否し、その後に別画像で変換できること。
- 2000×1000の画像が1600×800へ縮小されること。
- 共通倍率、背景切り替え、拡大後の左右スクロール連動。
- 1440pxのPC表示と390pxのスマートフォン表示をスクリーンショットで確認。
- 320px幅でも横方向にはみ出さず、モバイルの元画像／SVG切り替えが動作。
- 正常操作中の未処理JavaScript例外なし、画像アップロード／外部通信なし。

Safari・Firefox・実機のiOS/Android、Cloudflare公開URLでの確認は未実施。
処理時間やメモリ使用量は端末と入力内容に依存し、全入力についての性能保証はしていない。
