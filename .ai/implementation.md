# SVG変換室の実装方針

ユーザーと合意した、このプロジェクト固有の方針です。初期テンプレートのJavaScript前提より優先します。

- 1ページ完結の日本語ラスタ画像→SVG変換ツール。
- UIはダーク背景のツール風デザイン。プレビュー領域を広く取り、PCは設定を左に置き、元画像とSVGを並べる。モバイルは縦積み、画像を切り替える。
- アプリのスクリプトはTypeScript、strict有効。関数宣言を基本とする。
- ReactなどのUIフレームワークは使用しない。Vite・Nunjucks・既存のFLOCSS派生SCSS構成を継続する。
- ユーザー指定のvtracerを利用する。画像はサーバーへ送信せず、ブラウザのWeb Worker内でWasmを実行する。
- 公式npmのWasmを固定バージョンで使用し、Node向けローダーのみをブラウザ用に変換する。手順・ハッシュ検証・ライセンスを維持する。
- Cloudflare PagesのGit連携による静的公開を想定。Wasmをリポジトリに含め、公開ビルドにはRustを要求しない。
- 通常の検証は `yarn test` と `yarn build`。UI変更時はブラウザでも操作と表示を検証する。
- 初期版の制限、透明度、入力上限などはREADMEを参照する。

## デザインの基準

背景 #171b24、パネル #202631、境界 #3a4455、本文 #edf1f7、補助テキスト #aab5c6、アクセント #80a3ff。
和文は端末内のBIZ UDPGothic / Yu Gothic UI等を使用し、外部フォントリクエストを発生させない。
左揃えの操作領域と、中央で比較する画像領域を分ける。装飾画像やヒーローの大面積表示より、変換操作と比較に面積を使う。
